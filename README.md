# 지식의 도미노 (Domino of Knowledge)
> **"내가 어디서 막혔는지 직접 찾고, 그 문제를 이해하는 데 필요한 지식만 거슬러 올라가 배운다."**

2022 개정 교육과정 기준 **수학(기존 유지)**, **물리(신규 확장)**, **화학(신규 확장)** 3대 과목 통합 학습 웹 애플리케이션입니다.

---

## 🌟 주요 특징 및 구현 내용

1. **깔끔하고 밝은 모던 UI (Clean & Bright Aesthetic)**
   - 화사한 파스텔 톤과 가독성 높은 한국어 폰트(Pretendard), 깔끔한 카드 레이아웃
   - 과목별 테마 컬러: 📐 수학 (인디고/바이올렛), ⚡ 물리 (오션블루/스카이), 🧪 화학 (에메랄드/민트)

2. **사용자 직접 API 키 설정 (User-Input Gemini API Key)**
   - 우측 상단 **"API 키 설정"** 버튼을 통해 사용자가 본인의 Google Gemini API 키를 직접 입력 및 검증
   - 브라우저의 `localStorage`에만 안전하게 저장되어 외부 노출 방지
   - API 키가 없을 때도 2022 개정 교육과정 기준의 풍부한 **대표 예제 모드**로 즉시 모든 기능 체험 가능

3. **최신 제미나이 3.5 플래시 (Gemini 3.5 Flash) 지원**
   - 모델 선택 기본값: `gemini-3.5-flash` (Gemini 2.5 Flash, 1.5 Flash 등 자유 선택 가능)

4. **완벽한 수학·과학 기호 표기 (Pristine LaTeX / KaTeX)**
   - `left`, `right` 같은 영어 원문 토큰 누출을 원천 차단하는 수식 정제기 탑재
   - 분수, 제곱, 벡터($\vec{F}$), 시그마($\Sigma$), 화학식($\mathrm{CH_4}$, $\mathrm{CO_2}$), 반응 화살표($\longrightarrow$) 완벽 렌더링

5. **2022년 개정 교육과정 단원 체계 적용**
   - **수학**: 공통수학1, 공통수학2, 대수, 미적분Ⅰ, 확률과 통계
   - **물리**: 물리학(일반선택) - Ⅰ. 역학과 에너지, Ⅱ. 전자기와 양자, Ⅲ. 파동과 정보 통신
   - **화학**: 화학(일반선택) - Ⅰ. 물질의 구성과 화학식량, Ⅱ. 원자의 구조와 주기성, Ⅲ. 화학 결합과 분자의 세계, Ⅳ. 화학 반응과 에너지
   - 상단 **"2022 개정 단원표"** 모달을 통해 전체 단원 구조 조회 가능

6. **과목별 인터랙티브 시각화 모형**
   - **물리**: 물체에 작용하는 힘의 방향과 크기를 보여주는 실시간 **자유물체도(Free Body Diagram, FBD)** 캔버스
   - **화학**: 반응 전후 **분자 입자 모형** 및 실시간 **몰(mol) 변환 실험기** ($m \leftrightarrow n$)
   - **수학**: 대각선 십자 곱셈 인수분해 구조 모형

## 🚀 실행 방법

### 1. 패키지 설치
Python 3.10+ 환경에서 다음 명령어로 필수 라이브러리를 설치합니다.
```bash
pip install fastapi uvicorn requests
```

### 2. 서버 실행
```bash
python app.py
```
또는
```bash
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```

### 3. 브라우저 접속
웹 브라우저를 열고 다음 주소로 이동합니다:
```
http://127.0.0.1:8000
```

## 🧭 학습 흐름 (6단계 루프)

1. **문제 업로드 또는 입력**: 학생이 어려운 문제 사진을 올리거나 질문을 텍스트로 입력 (또는 대표 예제 선택)
2. **풀이 과정 단계별 표시**: AI가 3~5개의 의미 있는 큰 사고 단계(단계명 + 핵심 공식)로 정리하여 제공
3. **이해하지 못한 단계 선택**: 학생이 자신의 풀이와 비교한 뒤, 막힌 단계의 **'이 과정이 이해되지 않아요'** 버튼 클릭
4. **개념 역추적 (도미노 체인)**: 막힌 단계의 핵심 개념 $\rightarrow$ 선수 개념 1 $\rightarrow$ 선수 개념 2를 도미노 블록 형태로 시각화
5. **기초 개념 집중 학습 & 확인 퀴즈**: 
   - 1~2문장 핵심 직관 요약
   - 공식과 기호/단위 의미
   - 인터랙티브 시각자료 (FBD / 몰 변환기 / 인수분해 모형)
   - 단계별 적용 예제
   - 정답 노출 없는 4지선다 확인 문제 $\rightarrow$ 제출 후 정답 해설 및 착각하기 쉬운 오답 분석 제공
6. **원래 문제로 복귀**: 개념 학습을 완료하면 원래 문제로 돌아와 막혔던 단계에 **'개념 보완 완료 ✓'** 상태가 반영되며, 끝까지 스스로 문제를 해결할 수 있도록 유도
